# 03 - Services, selectors and DNS
Prerequisite: 02. Goal: separate Pod identity from stable service identity.

Tasks:
1. Before opening service.yaml, write a ClusterIP Service named web with selector
   app=web, port 80 and targetPort 80. Compare with the reference and apply it:
   `kubectl --context kind-k8training -n k8training apply -f training/manifests/service.yaml`.
2. Run Check.ps1 -Lab 3. It performs a DNS/HTTP request from a temporary Pod.
3. Run `kubectl --context kind-k8training -n k8training port-forward service/web 8080:80`.
   Open http://localhost:8080; stop forwarding with Ctrl+C.
4. Inspect `get endpointslices -l kubernetes.io/service-name=web`.

Break/fix: edit the live Service selector with
`kubectl --context kind-k8training -n k8training edit service web`;
set app to missing. Observe EndpointSlices and failed internal access.
Restore by applying service.yaml, then repeat the check.
Pass manually: explain selector vs targetPort, show internal HTTP succeeds
after repair, and explain why ClusterIP is not a public internet address.
