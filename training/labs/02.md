# 02 - Scaling and self-healing

Prerequisite: 01. Goal: predict a controller's response.

Tasks:

1. Scale web to three replicas:
   `kubectl --context kind-k8training -n k8training scale deployment/web --replicas=3`.
2. List Pods. Record a Pod's name and UID, delete that one Pod using its name,
   and watch with `get pods -w` (Ctrl+C stops watching).
3. Confirm the replacement has a new UID and web returns to three Ready Pods.
4. Run Check.ps1 -Lab 2.

Pass manually: retain before/after UIDs; explain why deleting a Pod does not
scale down a Deployment. Discuss why three Pods on one node do not survive
loss of that node.
Break/fix: scale to zero; predict availability; restore to three.
Reset: repeat scale --replicas=3. Applying web.yaml resets replicas to two.
