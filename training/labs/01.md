# 01 - Meet the cluster

Prerequisite: SETUP.md complete. Goal: distinguish cluster, node, Pod and Deployment.

Tasks:

1. Draw browser -> Service -> Pod -> container. Identify the control plane.
2. Create the namespace; apply the starting application:

```powershell
kubectl --context kind-k8training create namespace k8training
kubectl --context kind-k8training -n k8training apply -f training/manifests/config.yaml -f training/manifests/web.yaml
kubectl --context kind-k8training -n k8training get deployments,replicasets,pods -o wide
powershell -NoProfile -File training/scripts/Check.ps1 -Lab 1
```

3. Inspect one Pod with describe. Locate its image, node, events and owner.

Pass manually: both explain desired state vs observed state and why the
Deployment created a ReplicaSet. Record two Pod names and the node name.
Break/fix: request a nonexistent Pod with get; interpret NotFound and list
the real names. Re-run this lab by applying the two files; create namespace
only if absent.
