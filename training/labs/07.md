# 07 - Least privilege
Prerequisite: 06. Goal: prove an identity's permissions.

Tasks:
1. Write a Role granting only get/list Pods, and bind it to ServiceAccount
   observer. Compare with rbac.yaml and apply the reference.
2. Run Check.ps1 -Lab 7. It impersonates observer to check permissions.
3. Test explicitly:
```powershell
kubectl --context kind-k8training -n k8training get pods --as=system:serviceaccount:k8training:observer
kubectl --context kind-k8training -n k8training get secrets --as=system:serviceaccount:k8training:observer
```
The first must succeed, the second must be Forbidden.

Break/fix: delete rolebinding observer-pods; verify the allowed operation is
denied; restore rbac.yaml and rerun.
Pass manually: explain Role vs RoleBinding vs ServiceAccount, record allow/deny
output, and explain why a Pod does not automatically use observer just because
that account exists. Impersonation works here because kind's lab user is admin.
Do not grant cluster-admin as a repair.
