# 04 - Configuration and practice Secrets

Prerequisite: 03. Goal: distinguish configuration from an image.

Tasks:

1. Edit config.yaml content to include BOTH learner first names; apply it.
2. Predict whether the image changes. Restart web to avoid waiting for volume
   propagation:
   `kubectl --context kind-k8training -n k8training rollout restart deployment/web`.
3. Use the HTTP check from lab 03 to inspect the page and confirm both names.
4. Create a fake-only Secret:

```powershell
kubectl --context kind-k8training -n k8training create secret generic practice --from-literal=token=not-a-real-secret
kubectl --context kind-k8training -n k8training get secret practice
powershell -NoProfile -File training/scripts/Check.ps1 -Lab 4
```

If practice already exists, reuse it. Do not use a real token.
Break/fix: remove web-content with delete configmap web-content, restart web,
and inspect events on the new Pods. Restore config.yaml and wait for rollout.
Pass manually: both names visible over HTTP; image unchanged; explain why base64
is not encryption and why a Secret requires access controls. This Secret is
deliberately not consumed by the app; stretch task: inject it as an environment
variable into a disposable Pod without printing the value.
