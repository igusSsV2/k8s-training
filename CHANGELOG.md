# Changelog

Each GitHub Release contains its dated change history and links to the merged
PR and related issues. A complete, cumulative `CHANGELOG.md` is attached to each
release and included in its ZIP. See [published releases](https://github.com/igusSsV2/k8s-training/releases).

This source file is an index, not an assertion that a development version has
already been published. Reviewed entries in [changes/](changes/) are the source
of release notes; the release job assigns their actual version and date.
Generated history lives in release assets so publishing never needs a bot commit
directly to `main`.

## Delivered before release automation (unversioned)

- Eight guided Kubernetes lessons and a browser learning dashboard.
- Three independent troubleshooting incidents with cluster setup, checks and cleanup.
- Local web controls with background PowerShell execution, real progress, and
  startup/shutdown scripts ([#3](https://github.com/igusSsV2/k8s-training/issues/3)).
- Issue/branch/PR workflow and documentation expectations.

These changes are included in the first automated release. No earlier release
tags or dates have been invented.
